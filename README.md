# CCARF Practice Flashcards

Interactive flashcards for Claude Certified Architect – Foundations practice exams.

## Live demo

**GitHub Pages:** https://aniketchanana.github.io/test-repo/

## Papers

| Paper | Description |
|-------|-------------|
| Paper 1 | Full practice exam · 60 questions |
| Paper 2 | Quick drill · 15 questions |
| Paper 3 | Foundations practice set · 60 questions |

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Progress is stored in `localStorage` for one active paper at a time. Reset returns you to paper selection.
